# GitHub 发布检查清单

这些项目需对最终发行物逐项确认，不能因存在此文档就视为完成。

- [ ] 完整 Git 历史与待上传附件秘密扫描；轮换曾明文分享的密钥。
- [ ] 排除 research、本机数据库、运行日志、凭据文件及临时测试包；不执行无差别 `git add .`。
- [ ] 最终包含 Apache-2.0 LICENSE、NOTICE、第三方声明和 SBOM。
- [ ] 按实际分发范围完成 `resources/compliance/LICENSE-REVIEW.md` 中的剩余材料核对。缺独立文件不等于无授权，检查已有源码注释与可信上游证据。
- [ ] MinGit 对应版本和随带组件的适用源码、构建材料及分发方式落实；不能将已有上游链接写成已交付完整源码。
- [ ] 同版本 EXE、目录 ZIP、SHA-256 和发布说明一致；仅上传本次正式产物。
- [ ] 独立 Windows 干净机、普通用户、无开发环境验收；实际网络边界和跨机数据迁移测试。
- [ ] 真实模型从需求澄清到生成安装、修改、导出的完整链路；模型费用由服务商账单核对。
- [ ] Linux/UOS 如发布新版本，另附该版本实机结果，不复用旧 Windows 证据。
- [ ] GitHub 私密漏洞报告、秘密扫描/推送保护、依赖告警按仓库适用能力启用；CI 首次远程运行通过。
- [ ] 标记 Pre-release，写明未签名和已知限制。不要要求用户绕过系统安全拦截。

当前未购买/配置代码签名证书，未操作远程仓库设置，未公开发布。签名可后续改善；剩余源码及许可材料不应伪造为已完成。
