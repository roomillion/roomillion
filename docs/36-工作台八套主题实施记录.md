# 工作台八套主题实施记录

## 1. 本次交付

`0.3.0-alpha.24` 为千万间 Roomillion增加统一的外观主题系统。“工作台设置”位于左侧栏底部，完整栏显示名称和当前主题，图标栏保留“设”字入口。用户点击主题卡片后立即预览并保存，不需要额外确认。

主题只作用于工作台外壳、主页、顶部标签、菜单、弹窗和 AI 创建工作区。普通房间仍按自己的 HTML/CSS 和主题运行，工作台不会强制改写房间配色。

## 3. 持久化与多窗口同步

当前主题 ID 保存在渲染进程同源本地存储的 `zhibian.appearance.theme.v1`。启动主工作台或稍后打开 AI 独立窗口时，页面先读取该值并恢复主题。

已打开的主窗口与 AI 独立窗口通过同源存储事件和 `BroadcastChannel` 同步。主题变化还会通过最小化 IPC 将经过固定白名单校验的主题 ID 发送给当前 Electron 窗口，用于同步：

- 窗口底色；
- 原生标题栏覆盖区颜色；
- Windows 最小化、最大化和关闭按钮的符号颜色。

渲染页不能向主进程传入任意颜色，只能选择八个固定主题 ID，避免把外观设置变成任意原生窗口参数入口。

## 4. 主要实现

- `src/main/workbench-theme.cjs`：八个主题 ID 的原生窗口安全白名单，以及标题栏和窗口底色适配。
- `src/main/ipc.cjs`、`src/preload/workbench-preload.cjs`：仅向可信工作台窗口开放 `setTheme(themeId)`。
- `src/renderer/index.html`：工作台设置入口、日间/夜间分组和八张可视化主题卡片。
- `src/renderer/app.js`：选择、即时应用、持久化、启动恢复和多窗口同步。
- `src/renderer/styles.css`：共享语义变量、八套调色板和主要工作台组件覆盖。
- `test/workbench-theme.test.cjs`：主题数量、日夜分组、无效 ID 拒绝和原生窗口更新测试。
