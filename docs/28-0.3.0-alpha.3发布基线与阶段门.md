## 2. 已进入基线的能力

- 七个离线示例房间、27 个固定版本官方模块和公共依赖去重。

- Pi Agent 持续会话、工具时间线、停止与排队、图片附件、房间创建和原位修改。
- 普通 `mimo-v2.5` 的文本与图片输入；`mimo-v2.5-pro` 只允许文本输入。
- 房间标签、无刷新独立窗口、侧边栏右键卸载、保留数据卸载和彻底卸载。
- 私有 SQLite、加密 `.zdata` 备份、MinGit 检查点、脱敏诊断和 GB 级文本有界读取。
- `.room` 完整性、路径可移植性、权限预检、外部依赖许可证与哈希展示。

## 4. 固定发布流程

```powershell
npm run release:portable
npm run pilot:kit
```

第一条命令自动递增预发布小版本、重建资源、运行测试并输出固定名称的便携版。第二条命令从 `package.json` 自动读取当前版本，生成同版本的 Windows 试点验收包；包内验证脚本从 `SHA256SUMS.txt` 自动识别便携版文件名，不再硬编码旧版本。

## 5. 当前机器无法替代的阶段门

1. 至少两套无开发环境的 Windows 普通用户环境完成离线、自包含、SmartScreen、杀毒软件和真实任务验收。
2. 5～20 名非开发内部用户完成试点并达到《14-0.2 干净机试点验收手册》的成功率指标。
3. 锁定具体统信 UOS x64 版本、补丁、桌面环境和设备，在实机重新验证 Git、WebGL/WASM、中文输入、拖放、文件选择、SQLite 和内网 AI。
4. 正式公开发布前取得应用代码签名证书与品牌图标，并完成许可证及安全团队复核。

## 6. v1.0 前仍需研发

- 房间发布者密码学签名与组织信任策略。
- room-spec@1、room-app@1、Room SDK 和 v1 官方模块目录的兼容冻结及迁移策略。
- 30～50 条真实需求金标评测、Agent 上下文压缩、工具确认和 PDF/TXT 等通用附件。
- 用户级免管理员安装版、离线升级与回滚机制、自动化持续集成。
- CSV/JSONL 流式分析与导出、Office 标准组件、3D 素材白名单和性能档位。
