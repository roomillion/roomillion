# 0.4.0 发布安全审查

审查日期：2026-09-23。对象：提交 `0f4b02ffe5ef609fb8982f2346b46060aa541986` 和本机同版本 Windows x64 构建。检查已执行，但**不能据此宣布 0.4.0 已获正式公开发布的安全放行**。尚未创建 GitHub Release 或发布标签。

## 已核对的证据

- `package.json`、锁文件、SBOM 和解包后 `app.asar` 的版本均为 `0.4.0`；Pi Agent Core / Pi AI 均为 `0.87.1`。本地 `main` 与 `origin/main` 指向同一提交，工作区干净。
- 311 项自动测试、源码冒烟和解包后的 Windows 冒烟通过；便携 ZIP 完整性检查通过。包内只发现八个公开示例，没有用户数据、私有房间、`.env`、Agent 会话或凭据目录。
- NAS 包 `Roomillion-0.4.0-Windows.zip` 含三种 Windows 产物、SHA-256、许可证和说明；本地 SHA-256 为 `90959f3d15ef8eadb60d1f124afc84342b7d2220d6da986cc2baaaccca436dab`。NAS 上传后的字节数与本地一致，均为 `574323057`；这项验证不是远端密码学哈希校验。
- 对当前工作文件和全部可达 Git 历史做了高置信度密钥模式扫描：分别检查 1532 和 1519 个文本对象，未命中项目私钥或常见服务 Token 格式。另对四个最终二进制/ZIP 共 1,150,202,844 字节做原始字节扫描，未命中上述模式。规则无法证明不存在未知格式的秘密。
- 使用经官方 SHA-256 文件校验的 Gitleaks 8.30.1 对全部可达提交（17 个提交，约 50 MB）扫描。四项 `generic-api-key` 告警均位于 `xml-js@1.6.11` 的上游 `package.json` 覆盖率脚本；本地文件与 npm 官方 tarball 字节相同，SHA-256 为 `71b38b1b2915848c890fe8c5effd006b61aff674e163fe87cf47aa0dbb2f61ba`。这证明内容来自公开上游包，不证明其所含 Token 字符串无效。
- Gitleaks 对 NAS 文件夹扫描出现 11 项通用规则告警：四项为上述 `xml-js` 元数据，七项位于 ASAR 二进制，涉及上游 SDK 类名和模型数据文件名。将 ASAR 解包后对应用文件扫描未发现告警；由于扫描工具忽略 `node_modules` 且读取 ZIP 内两个文件时报告解析错误，不能把该次扫描称为完整的包内秘密证明。
- 工作台、房间与受控浏览器的 Electron 配置启用 `sandbox`、`contextIsolation`、`webSecurity`，关闭 `nodeIntegration`；房间窗口拒绝任意新窗口与未授权权限请求。现有测试覆盖权限隔离和撤销路径；这不是独立渗透测试。

## 尚未满足的公开发布门槛

1. 使用 npm 官方 registry 审计完整锁文件得到 **2 项 high、2 项 moderate**：`image-size` 经 `pptxgenjs` 引入，`uuid` 经 `exceljs` 引入。仅检查生产依赖得到零项，但这两个开发依赖会进入官方房间模块，不能据此忽略。自动建议回退其上层包的大版本，尚未采用；需结合实际输入路径评估并修复或记录经审核的风险接受。
2. 自动许可清单仍列出 13 个未发现独立 LICENSE/COPYING 文件的来源包；MinGit/Git 及随带组件的对应源码、构建材料和交付方式尚未落实。见 [`resources/compliance/LICENSE-REVIEW.md`](../resources/compliance/LICENSE-REVIEW.md)。不得宣称“全部合规已认证”。
3. Windows 安装版和便携 EXE 均未签名；尚无独立干净机、普通用户、真实模型多轮创建/修改/导出，以及跨机迁移的本版本验收。Linux/UOS 与 macOS 不在本次 0.4.0 Windows 构建验证范围内。
4. 仓库已配置 push / pull_request 的 Windows CI 工作流；GitHub 仓库 API 对当前未认证访问返回 404，浏览器亦未显示该仓库，因此本轮**无法核实**远端 CI 结果、私密漏洞报告、秘密扫描、推送保护和依赖告警设置。仓库管理员需在已登录的 GitHub 界面逐项确认。

在以上门槛得到处理与复核前，NAS 包适合作为内部验证产物；不要据此发布无保留的稳定版公告。
