# 房间独立窗口与标签拖出实施记录

> 实施日期：2026-09-02
> 状态：第一版已完成；单元测试与真实 Electron 离线多窗口验收通过

## 1. 用户体验

每个已经打开的房间都可以用三种方式管理：

1. 把房间标签拖到千万间 Roomillion主窗口之外，松开后变成独立窗口；
2. 点击标签上的 `↗`，或顶部“独立窗口”按钮直接弹出；
3. 点击独立标签上的 `↙`，或关闭独立窗口，把房间收回工作台。

标签上的 `×` 表示真正关闭房间运行实例；独立窗口右上角的系统关闭按钮默认表示“收回工作台”，避免用户误关正在工作的房间。独立房间标签会使用不同底色并显示“独立窗口”状态。

支持同时弹出多个房间，也支持移动到其他显示器。每个房间最后一次独立窗口的位置和尺寸记录在本机 `room-window-state.json`；下次再次弹出该房间时复用，并根据当前显示器工作区修正，避免窗口落在已经拔掉的显示器之外。

## 2. 状态为什么不会丢

实现没有创建第二份房间页面，也没有刷新 URL，而是把同一个 Electron `WebContentsView` 从主窗口的 `contentView` 移到独立 `BrowserWindow.contentView`：

```text
工作台主窗口                         房间独立窗口
contentView                           contentView
    │                                     │
    └──── 同一个 WebContentsView ──────────┘
          同一个 webContents.id
          同一份 JS 内存 / Canvas / 游戏进度
          同一 Room SDK 权限映射
```

因此下列状态会保留：

- 没有写入数据库的页面临时状态；
- 3D 游戏场景、得分和动画循环；
- 表单输入、滚动位置和当前页面；
- Room SDK 的数据库、文件、超长文本和 AI 权限；
- 房间专属 Session Partition 与 CSP。

关闭独立窗口归位时仍是相同的 `webContents.id`。只有关闭标签、删除房间、更新程序或退出工作台时，才真正销毁房间 WebContents。

## 3. 拖出判定

标签使用浏览器原生拖动手势，但是否弹出由主进程判断当前系统鼠标位置：

- 鼠标仍在主窗口矩形内：不弹出，避免普通点击或短距离拖动误触；
- 鼠标离开主窗口：创建独立窗口并迁移视图；
- 多显示器坐标统一由 Electron `screen` API 处理；
- 渲染进程不能自行指定任意窗口坐标或创建新页面。

## 4. 安全边界

- 独立窗口只是新的宿主容器，不改变房间 Manifest、权限或网络策略；
- 房间仍保持 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true` 和 `webSecurity: true`；
- 独立窗口自身不加载外部页面，拒绝导航和新窗口；
- Room SDK 调用仍按原房间 WebContents 的 sender ID 鉴权；
- 窗口状态文件只保存房间 ID、位置和尺寸，不保存房间数据、页面内容、API Key 或用户输入；
- 关闭、删除、恢复和更新房间时会同时清理对应独立窗口，避免孤立 WebContents。

## 5. 代码位置

- `src/main/room-view-manager.cjs`：视图迁移、独立窗口生命周期、原生关闭归位、多显示器约束和位置持久化；
- `src/main/ipc.cjs`：只允许工作台调用的 detach/dock IPC；
- `src/preload/workbench-preload.cjs`：最小独立窗口 API 和状态事件；
- `src/renderer/app.js`：标签按钮、拖出手势、状态同步和收回操作；
- `test/room-view-manager.test.cjs`：六项独立窗口专项测试；
- `src/main/index.cjs`：真实 Electron 多窗口冒烟。

## 6. 验收结果

- 该阶段全部自动测试为 94/94；截至 2026-09-04 的 alpha.3 主线为 101/101；
- 同一个 `WebContentsView` 和 `webContents.id` 在拖出、收回前后保持不变；
- 鼠标在主窗口内时不会误弹出；
- 独立窗口系统关闭按钮会阻止销毁并将视图安全收回；
- 关闭标签会同时销毁独立窗口和房间 WebContents，重复关闭不报错；
- 窗口位置和尺寸可以持久化并校验；
- 真实 Electron 中自由 Three.js 房间成功移入独立窗口，页面内 `score: 17` 和“已重新开始”状态在归位后仍存在；
- 归位后 WebContents ID 不变，随后可以安全关闭；
- Electron 离线审计普通互联网出站尝试为 0。

## 7. 当前边界

第一版支持“拖动标签到窗口外”和“关闭/点击 ↙ 收回”。尚未实现把整个独立窗口拖到标签栏上方时自动吸附合并，也没有独立窗口间的标签组合；这两项属于后续交互增强，不影响当前多窗口运行和状态保持。
