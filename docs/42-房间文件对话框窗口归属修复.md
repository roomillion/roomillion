# 房间文件对话框窗口归属修复

版本：0.3.0-alpha.32；日期：2026-09-12。

## 原因与改动

物资台账通过 `room.files.exportText` 导出 CSV。此前该接口始终用主工作台作为系统保存对话框的父窗口，导致独立房间导出时主工作台被带到前台。

现在由房间窗口管理器在调用时解析当前宿主窗口：独立房间绑定自己的窗口，合并回工作台后绑定主窗口。窗口已关闭时返回明确错误，不转向其他窗口。继续通过 IPC 发送方识别房间并检查权限，房间不能指定别人的父窗口。

统一修复六个文件接口：`exportText`、`exportBinary`、`pickText`、`pickBinary`、`binaryOpen`、`largeTextOpen`。不修改房间内容、导出数据或文件格式，也不使用永久置顶。

## 验证范围

- 170 项自动测试通过。新增覆盖六个接口在嵌入、独立、重新合并状态下的父窗口；取消操作；权限拒绝；未知调用方；窗口关闭；CSV 和二进制保存内容。
- Windows Electron 源码冒烟通过：点击物资台账实际“导出 CSV”按钮，经 preload 与 IPC 写出 CSV，检查对话框父窗口，再验证取消和合并后的归属。
- 冒烟替换了系统文件选择器返回值，避免等待人工操作；未将该自动验证等同于人工检查 Windows 原生保存对话框的前后台表现。
- 源码报告：`release/alpha.32-dialog-source-smoke.json`。
- 打包后报告：`release/Roomillion-0.3.0-alpha.32-Packaged-Smoke.json`。

使用新版工作台即可生效，已有房间不需要重新生成或导入。
