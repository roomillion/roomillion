# AI模型能力测试房间

## 1. 目标

“AI模型能力测试”用于快速判断主工作台中某个模型配置是否适合千万间 Roomillion 的房间生成 Harness。首版只测两类基础能力：聊天理解与图片识别。它不等价于完整的代码生成评测，但可以低成本暴露指令不遵循、JSON 不稳定、权限理解错误、长需求遗忘、中文 OCR 弱和错误截图定位弱等高频问题。

房间只调用 `window.room.ai`，不保存 API Key 或服务地址，也不申请普通联网权限。三张视觉题图片由房间本地 Canvas 固定生成，不依赖外部素材；数据库只属于当前房间。

## 2. 类别与等级

| 类别 | 计分方式 | 适合用途 |
| --- | --- | --- |
| 聊天能力 | 文本题平均分 | 快速筛选指令遵循和需求理解能力 |
| 图片识别 | 视觉题平均分 | 筛选参考图理解、中文 OCR 和截图排错能力 |
| 综合能力 | 聊天 60% + 图片 40% | 作为当前 Harness 的默认适配参考 |

| 等级 | 聊天题 | 图片题 | 综合预计 Token |
| --- | ---: | ---: | ---: |
| 快速 | 2 | 1 | 约 1,500～3,000 |
| 标准 | 4 | 2 | 约 3,000～7,000 |
| 深度 | 6 | 3 | 约 6,000～12,000 |

预计值会因模型分词、视觉计价和返回长度变化。房间优先记录 Provider 返回的输入、输出和总 Token；Provider 不返回用量时才使用本地估算，并在排行榜标注“估”。

## 3. 题目设计

聊天题依次覆盖：精确指令遵循、房间 JSON 草案、Harness 状态故障归因、3D/数据库/AI 权限路由、跨段长需求事实抽取、越权调用自检。图片题依次覆盖：中文仪表盘的文字和趋势、折叠侧栏与权限状态、带源码和检查器信息的启动错误截图。

每题答案空间都在提示中被约束为确定字段或枚举值，评分由房间本地规则完成，不调用另一个 AI 评分。这样可以复现分数、控制 Token，也避免裁判模型偏差。视觉模型目录若声明不支持图片，图片题直接记 0 分；这反映能力边界，而不是运行异常。

分数等级为：S（90～100）、A（80～89.9）、B（70～79.9）、C（60～69.9）、D（0～59.9）。只有“同类别、同等级、同题库版本”的成绩可以直接比较。

## 4. 排行榜与数据

每次完整评测写入 `benchmark_runs`，包括题库版本、自定义题集指纹、模型配置 ID、模型与 Provider 显示名、类别、等级、总分、聊天分、图片分、等级、Token、耗时、错误数、脱敏设置和逐题原题/回答。排行榜对每个模型配置只显示当前同试卷筛选档位下的最好成绩。点击排行榜成绩或本次评测的已完成题目，可以查看原始问题、模型原始回答、评分、Token、耗时、错误摘要与自定义断言。

设置只包含模型输入能力、上下文窗口、模型输出上限、测试温度和题库版本。测试图片不落库，凭据、认证头和 Provider 服务地址不会进入房间。用户可在房间中确认后清空全部排行榜数据。

## 5. 使用方法

1. 在主工作台“AI 能力中心”配置一个或多个模型。
2. 从“示例房间”安装并打开“AI模型能力测试”。
3. 选择模型、类别与等级；首次建议使用“标准 · 综合能力”。
4. 阅读预计 Token，确认后开始。评测按顺序调用，失败的单题记 0 分并保留错误摘要，其余题继续执行。
5. 在右侧切换类别与等级查看同档排行榜。模型配置更新后，房间会自动刷新脱敏模型目录。

题库内容或权重发生变化时必须提升 `suite_version`，不能把新旧题库成绩混在同一排行榜中。

## 6. 自定义题目

点击“自定义题目”可以新增、编辑、启停和删除本地题目。聊天题只发送提示词；图片题可复用三张内置图，也可选择一张不超过 2 MB 的 PNG、JPEG 或 WebP。选择的图片会保存在房间私有数据库中，评测时通过主工作台 AI Gateway 发送给所选模型。

自定义题采用安全 JSON 断言评分，不接受正则表达式或 JavaScript。快速题会进入快速、标准和深度档，标准题会进入标准和深度档，深度题只进入深度档。启用题目的 ID 与最后更新时间会形成 `custom_set` 指纹；修改或启停题目后，排行榜不会与旧试卷混排。完整书写规则见《33-自定义模型评测题目规则》。
