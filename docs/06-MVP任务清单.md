# 千万间 Roomillion MVP 任务清单

## 1. 使用说明

本清单用于从技术探针推进到 MVP，不代替 PRD 或架构设计。建议导入任务管理工具并保留任务编号。每项应补充负责人、计划迭代、实际结果和证据链接。

状态建议使用：`待开始 / 进行中 / 阻塞 / 已完成 / 已取消`。

## 2. 全局完成定义

任务只有同时满足以下条件才算完成：

- 实现已合入主分支并通过评审。
- 有与风险相称的自动化测试。
- Windows 和指定 UOS 上完成必要验证。
- 无新增运行时联网下载依赖。
- 权限、兼容性或格式发生变化时已同步更新文档。
- 日志和测试产物不包含真实 API Key 或用户敏感数据。

## 12. 建议的最先十项

若现在立即启动，按以下顺序推进：

1. A-01：锁定目标系统和设备。
2. A-02：确定真实业务样例。
3. A-03：建立工程与决策流程。
4. A-04：固定候选技术版本。
5. B-01：建立安全 Electron 外壳。
6. B-03：实现 `room://` 加载。
7. C-01/C-03：实现最小 Manifest 和安全解包。
8. D-01/D-02：实现最小 Room SDK 和 SQLite。
9. E-02/E-03：嵌入 Pi 并连接内网 API。
10. F-04/G-01：验证内置 Bun 和 MinGit 完全不依赖系统安装。

完成这十项后进行第一次 Go/No-Go 评审，再决定是否扩展完整 UI。
