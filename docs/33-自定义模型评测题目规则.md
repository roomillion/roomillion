# 自定义模型评测题目规则

## 1. 设计目标

自定义题必须可离线保存、可复现评分、不会执行任意代码，并且适合千万间 Roomillion 房间生成 Harness。用户通过房间表单填写题目元数据与提示词，只需要手写“评分断言 JSON”。内部格式版本固定为 `zhibian-benchmark-case@1`。

概念上的完整题目如下，界面会分别编辑这些字段：

```json
{
  "format": "zhibian-benchmark-case@1",
  "title": "最小权限判断",
  "type": "chat",
  "level": "standard",
  "prompt": "请只输出 JSON……",
  "responseFormat": "json",
  "maxTokens": 320,
  "image": { "kind": "none" },
  "assertions": [
    { "path": "permissions.database", "operator": "equals", "expected": "private", "weight": 40 },
    { "path": "permissions.network", "operator": "equals", "expected": [], "weight": 20 },
    { "path": "hostModules", "operator": "includesAll", "expected": ["ui.chart@1"], "weight": 40 }
  ]
}
```

## 2. 字段规则

| 字段 | 规则 |
| --- | --- |
| `title` | 2～80 个字符，描述单一能力点 |
| `type` | `chat` 或 `vision` |
| `level` | `quick`、`standard` 或 `deep` |
| `prompt` | 20～6000 个字符；应明确输出格式、字段和禁止事项 |
| `responseFormat` | `json` 或 `text` |
| `maxTokens` | 16～2000 的整数 |
| `image.kind` | 聊天题为 `none`；图片题可选择内置图或本地上传图 |
| `assertions` | 1～12 条，权重均为 1～100 的整数，总和必须正好是 100 |

JSON 路径只允许英文字段名和点号，例如 `permissions.database`、`result.items`。不支持数组下标、通配符或表达式。纯文本题使用特殊路径 `$text`。

## 3. 安全操作符

| 操作符 | `expected` | 通过条件 |
| --- | --- | --- |
| `equals` | 任意 JSON 值 | 实际值与期望值相等；字符串会忽略首尾空白 |
| `numberEquals` | 可转换为数字的值 | 两边转成数字后相等 |
| `contains` | 单个值 | 字符串包含期望文字，或数组包含期望项 |
| `includesAll` | 1～20 项数组 | 实际数组或字符串包含全部期望项 |
| `oneOf` | 1～20 项数组 | 实际值等于其中任意一项 |
| `exists` | 不需要 | 路径存在且值不为 `null` |

系统不支持正则表达式、自定义函数、JavaScript、网络评分器或另一个 AI 裁判。

## 4. 示例

纯文本精确回答：

```json
[
  { "path": "$text", "operator": "equals", "expected": "OK", "weight": 100 }
]
```

房间权限与模块综合判断：

```json
[
  { "path": "database", "operator": "equals", "expected": "private", "weight": 25 },
  { "path": "network", "operator": "equals", "expected": [], "weight": 20 },
  { "path": "aiRoles", "operator": "contains", "expected": "general", "weight": 20 },
  { "path": "hostModules", "operator": "includesAll", "expected": ["graphics.three@1", "physics.rapier@1"], "weight": 35 }
]
```

图片 OCR 题：提示模型输出 `title`、`count` 和 `action` 后，可使用：

```json
[
  { "path": "title", "operator": "equals", "expected": "库存驾驶舱", "weight": 40 },
  { "path": "count", "operator": "numberEquals", "expected": 12, "weight": 30 },
  { "path": "action", "operator": "oneOf", "expected": ["导出 CSV", "导出表格"], "weight": 30 }
]
```

## 5. 编写建议

一个题目只测一个主要能力，不要把正确答案直接写成自然语言暗示。优先要求 JSON 与有限枚举，减少同义表达导致的误判。把关键约束放在提示词末尾再重复一次；图片题应要求模型同时回答 OCR 字段与布局/状态字段。先用快速档验证规则能正常得分，再启用到正式排行榜。

自定义题目最多保存 50 个；单张图片最大 2 MB，全部自定义图片合计不超过 20 MB，只支持 PNG、JPEG 和 WebP。图片与题目存放在房间私有数据库中；删除自定义题目不会删除历史成绩里已经保存的原题、回答和断言。
