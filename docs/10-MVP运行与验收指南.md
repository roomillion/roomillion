# 千万间 Roomillion MVP 运行与验收指南

## 1. 已交付什么

当前可运行版本是面向 Windows x64 的 `0.3.0-alpha.25` 技术预览，已经实现：

- 免安装、无需管理员权限的自包含 ZIP 目录便携程序；单文件格式仍保留，但未完成代码签名前以目录版为当前推荐。
- 工作台主页用卡片展示全部已安装房间，点击卡片直接打开；主页、AI 创建房间和普通房间都进入同一标签栏。
- AI 创建房间是完整的一级工作区，可以通过标签或顶部按钮移入独立窗口，关闭独立窗口时安全收回主工作台。
- 左侧栏目支持完整、仅图标和完全收起三态，并记住上次状态。
- “工作台设置”内置四套日间和四套夜间主题；选择后立即保存并同步主窗口、AI 独立窗口和原生标题栏，房间自己的主题不受覆盖。
- 侧栏缩进按钮位于 Codex 风格的顶部窗口拖动栏最左端；拖动栏右侧保留系统最小化、最大化和关闭按钮。
- 多标签自动压缩长标题并隐藏原生横向滚动条；超过 5 个标签时固定显示“全部标签”，实际溢出时同时显示前后浏览。顶栏严格保留右侧操作区，备份、恢复、导出、卸载位于“更多”菜单；房间运行时打开这两个下拉会临时避让原生房间视图，关闭后恢复原 WebContents。
- 左侧房间列表使用窄滚动条，默认弱化，鼠标移入列表后才明显显示。
- 房间导出可选择“只导出应用”或“应用和数据一起导出”，两者统一生成 `.room`；是否设置密码是独立选项，两种内容都可以有密码或无密码。
- “房间设置”完整列出 Manifest 申请的权限、稳定权限键、风险等级和当前授权状态；非必需权限可在此撤销，联网权限还会显示主工作台总开关限制。
- 每个房间独立使用 SQLite 数据库和键值存储；是否携带业务数据由导出者显式选择，与文件后缀及是否设置密码无关。
- 受控的文本文件选择与导出，以及 GB 级文本的宿主流式读取和后台搜索；房间不能直接获得任意本地路径。
- 沙箱化房间视图、关闭 Node 集成、隔离会话、阻止任意导航和房间渲染页的直接网络请求。
- 主界面“联网控制”全局开关，以及 Manifest 精确源声明、逐源授权和 `window.room.network` 受控 HTTP/HTTPS 接口；房间联网默认关闭，AI API 独立可用。
- 普通房间可声明 `browser.navigate` / `browser.download`，通过 `window.room.browser` 操作宿主隔离网页视图；网页不能接触 Room SDK、AI Key 或房间数据，并可随房间在主工作台和独立窗口间无刷新重挂。
- 通过 Pi AI 适配层调用 MiMo Token Plan、常见云端 Provider、OpenAI-compatible API 和内网兼容网关；一个提供商可一次批量启用多个模型，已连接与可导入区域明确分开；API Key 可只保存在进程内存，或由用户选择系统安全存储。
- AI 提供商使用工作台自绘可搜索目录，整行可点击并按类别展开，不依赖 Electron 原生下拉弹层。
- AI 根据自然语言输出严格的 room-spec@1；工作台按规格编译多页面、表单、列表、看板、图表、计算器和导出等不同房间，同时不执行 AI 返回的任意代码。
- Pi Agent 工作区支持持续对话、每个会话独立选择编程模型、工具时间线、图片粘贴/拖入/选择、自由 room-app@1 房间的草拟、测试、安装和原位修改。
- 内置物资台账、会议行动项、离线 3D 晶体挑战、AI 辩论场、AI模型能力测试和千万间浏览器六个示例；未配置 AI 时本地能力仍能使用。
- AI模型能力测试支持点击成绩查看逐题原问题、原回答和评分，也支持自定义聊天题、图片题与安全 JSON 评分断言；修改题集后自动使用新指纹隔离排行榜。

## 2. 最快运行方式

解压以下文件：

```text
release/Roomillion-0.3.0-alpha.25-Portable-Folder.zip
```

然后双击目录内的 `千万间 Roomillion.exe`。压缩包包含当前功能需要的 Electron、JavaScript 运行时代码、Pi AI 适配器、SQLite 实现和内置示例房间。用户无须安装开发工具；离线房间不依赖普通互联网。只有用户启用房间联网并对目标服务逐源授权时，联网房间才会访问相应业务 API；AI Token API 始终按 AI 能力中心的配置独立连接。

Windows 可能会提示“未知发布者”，因为 MVP 尚未购买和配置代码签名证书。该提示不代表程序需要管理员权限。

## 3. 建议演示流程

1. 启动便携版，确认默认进入主页，并以卡片看到所有已安装房间；点击任一卡片可直接打开。
2. 安装“物资台账”，新增和删除记录，关闭房间后重新打开，确认数据仍存在。
3. 再安装“会议行动项”和“AI 模型能力测试”，验证房间像网页标签一样切换，而且各自拥有独立数据空间。
4. 连续点击标签栏左侧的栏目按钮：第一次确认栏目缩成仅保留图标或房间首字的窄栏，第二次确认栏目完全消失、房间内容占满可用宽度；再次点击恢复完整栏目。
5. 打开“工作台设置”，依次试用林间青、海湾蓝、暖纸米、晨雾紫、深林夜、午夜蓝、紫晶夜和石墨橙；确认背景、卡片、菜单、弹窗、输入框、AI 对话区和系统标题栏协调变化。关闭设置并重启，确认上次主题被记住。
6. 点击“房间设置”，确认能看到该房间申请的全部权限、当前授权数量、每项权限键、风险等级和授权状态；取消一个非必需权限并保存，确认对应能力立即被收回。
7. 点击“AI 创建房间”，确认它和房间一样出现在顶部标签栏；点击标签 `↗` 或把标签拖出工作台，确认 AI 对话进入独立窗口，且主题与主工作台一致。关闭独立窗口后，确认同一会话收回工作台。
8. 把一个普通房间标签拖出主窗口，确认它在独立窗口继续运行；操作几步后关闭独立窗口，确认它带着原状态回到工作台。也可以使用标签 `↗/↙` 或顶部“独立窗口”按钮。
9. 在“物资台账”使用“读取文本”和“导出 CSV”，验证房间只能通过工作台授权访问文件。
10. 安装“AI 模型能力测试”，选择已配置模型运行题集；确认评分、耗时和结果明细正常显示。
11. 在工作台进入“更多 → 导出房间”，分别验证“仅应用/应用+数据”和“无密码/设置密码”四种组合，四种结果都应为 `.room`。无密码包可直接进入权限预检；有密码包必须先正确解锁。携带数据的包在确认页明确提示将恢复数据，完整性检查或密码验证失败不得覆盖已有数据。
12. 打开“AI 能力中心”，确认默认页面只列出已连接提供商。点击“添加提供商”，选择 MiMo Token Plan，粘贴一次 Key，同时勾选 `mimo-v2.5` 和 `mimo-v2.5-pro` 后启用；只有自定义内网接口才需要填写地址。
13. 打开“AI 创建房间”，在顶部切换当前对话的“编程模型”，输入“创建一个两页的项目协作房间：第一页显示任务统计和状态图表，第二页能录入任务并用看板管理；字段包含事项、负责人、截止日期、优先级和状态，支持搜索和 Excel 导出”，生成并打开新房间。
14. 再创建“含税报价计算器”，比较两个房间的页面、组件和操作，确认不是同一个固定模板。
15. 打开主界面“联网控制”，确认默认关闭；启用后，只有声明并获授权的房间业务 API 可以访问。再次关闭后，相关房间应收到状态变化并停止联网。
16. 安装“千万间浏览器”，在房间设置中确认它申请“浏览网页”和“网页下载”；打开联网总开关后访问一个网页，测试新标签、后退、收藏和下载保存窗口。再把该房间拖到独立窗口，确认已打开网页不刷新、标题和地址不丢失；关闭总开关后确认新导航被阻止。
17. 断开普通互联网后继续使用其他已安装房间；如果 Token API 仍可达，AI 创建也可以继续使用。浏览器房间会明确显示联网关闭。

注意：`.room` 是统一容器，并不代表一定包含或不包含数据。导出页会明确显示内容选项；不设置密码的“应用+数据”包可被接收者直接读取，适合可信环境。设置密码时会加密整个传输载荷，密码不会写入文件、日志或工作台配置，遗忘后无法恢复。

## 4. AI 配置

当前 MVP 使用 Pi AI 的 provider/model 目录。推荐流程是先连接提供商，再从可搜索目录中批量勾选模型：

- MiMo Token Plan（中国）：只填写一次 API Key，可同时启用 `mimo-v2.5` 和 `mimo-v2.5-pro`。
- 其他 Pi 内置提供商：按界面提示填写 Key，并从目录一次勾选一个或多个模型。
- 自定义 / 内网 OpenAI-compatible：填写组织提供的 Base URL、API Key，并按“每行一个模型 ID”导入。

Provider 和模型设置会保存在用户配置中。默认不记住密钥；用户主动选择“记住”时使用 Electron 系统安全存储加密，密钥不会进入房间、Git、普通 Provider JSON 或诊断报告。

主工作台的“默认模型”只是新建 AI 对话和未单独选择模型的房间的起点。每个 AI 创建房间对话可以在顶部独立切换编程模型；房间则通过 `window.room.ai` 的脱敏目录独立选择，不会互相覆盖。

## 5. 数据位置与卸载

开发模式、安装版和单文件便携 EXE 默认使用 Electron 的 `userData/mvp-data`，新配置通常在 `%APPDATA%\Roomillion\mvp-data`；已有旧版数据时继续识别 `%APPDATA%\智变工作台\mvp-data`。解压 ZIP 版默认使用解压目录中的 `Roomillion-data/`。单文件便携 EXE 首次启动时可选用默认位置，或自定义目录并在其中创建 `Roomillion-data/`；取消目录选择仍使用默认位置。用户可在“设置 → 房间位置”安排迁移，重启后复制数据并保留旧目录。

关闭主窗口时会询问关闭方式：

- “常驻后台”隐藏工作台和当前可见的独立窗口，保留已打开房间、AI 任务、受控浏览器和数据库连接；房间渲染器不会因窗口隐藏而被定时器节流。
- 点击系统托盘中的千万间图标恢复之前可见的窗口；托盘菜单中的“完全退出”会结束房间和后台任务。
- “完全退出”直接结束工作台；“取消”返回原窗口。

主要内容：

```text
mvp-data/
  registry.json          # 已安装房间注册表
  rooms/<room-id>/program/  # 房间程序
  rooms/<room-id>/data/     # 房间私有数据库和存储
```

删除便携 EXE 只会删除程序，不会自动删除用户数据。需要彻底卸载时，应先备份需要保留的数据，再手工删除上述目录。

## 6. 从源码运行

当前仓库已经锁定依赖版本。首次安装需要能访问 npm；安装完成后，日常开发和运行不需要重复下载。

```powershell
npm install --cache .npm-cache
npm start
```

常用命令：

```powershell
npm run build:example   # 重新生成全部内置示例 .room
npm test                # 运行核心服务测试
npm run smoke           # 启动 Electron 自动完成最小 UI/运行时验收
npm run package         # 生成 release/win-unpacked
npm run dist:portable   # 生成单文件便携版
npm run build:portable-folder # 为当前版本生成 ZIP 目录便携版
```

如果 Electron 下载在国内网络失败，可为安装阶段配置可访问的 Electron 镜像；这只影响开发机准备，不影响最终用户运行便携版。

## 8. MVP 有意保留的边界

以下内容不属于本次已完成能力：

- 统信 UOS、麒麟及其他 Linux 发行版打包与认证。
- Bun 房间后端进程。当前房间采用静态前端 + 宿主能力代理，最终用户也不需要 Bun。
- 任意 npm 包、任意 Shell、任意本地后端和通用 Docker 式容器。
- 组织级房间证书、公开市场和自动更新。
- CSV/JSONL 的结构化流式解析、超长文本流式改写与原子导出；当前版本先提供分块预览和纯文本搜索。
- 对来源不明的恶意房间提供浏览器级别以上的强安全保证。
