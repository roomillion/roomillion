## 3. 尚未完成的外部关卡

以下事项无法由当前单一开发环境替代：

1. 在一台从未安装 Node、npm、Git、Bun 的 Windows x64 普通用户电脑运行便携版。
2. 在物理断网或严格出网阻断环境完成本地闭环。
3. Windows Defender/组织杀毒软件扫描和误报记录；当前开发机的 Defender 命令行返回 `Product/Feature disabled`，不能作为扫描通过证据。
4. 5～20 名非开发内部用户的任务成功率与权限文案理解度。
5. 如决定公开分发，采购代码签名证书并验证 SmartScreen 信誉流程。

当前便携版的 Windows Authenticode 状态为 `NotSigned`。这些关卡未完成前版本称为“内部试点候选”，不称为正式稳定版。
