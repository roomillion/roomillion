## 1. 本次结论

按 P0、P1、P2 全量实施后，千万间 Roomillion 的官方房间模块由 27 个增加到 39 个，其中 37 个可由 AI 或房间直接选择，中文字体和 PDF fontkit 作为内部依赖自动补齐。新增模块全部是固定版本的浏览器资源，由工作台共享提供；房间只声明稳定能力 ID，不重复打包这些库，也不会在运行时执行 npm install 或访问 CDN。

12 个新增模块的实际离线资源合计 7,243,488 字节，约 6.91 MiB。这是解压后的共享资源大小，并不等于最终 ZIP 增量；最终压缩包大小以发布产物为准。

## 5. AI Harness 如何选用

房间 Agent 在检查能力时会得到两份信息：完整官方模块目录，以及根据当前用户需求由本地规则给出的 recommendedModules。模型仍可自由设计页面和交互，但最终 hostModules 必须经过本地白名单过滤和依赖展开；不存在的能力 ID 会被删除。

本地关键词兜底覆盖数据网格、拖拽看板、流程图、热力图、富文本、地图、矩阵、统计回归、图片裁剪、白板、D3 和知识图谱等常见说法。Agent 技能文档同时说明每个模块的全局对象与安全边界，因此模型不需要猜 npm 包名，也不会要求用户在线安装依赖。

选型遵循最小化原则：需求没有涉及某项能力时不声明对应模块。比如普通折线图仍优先使用轻量的 ui.chart@1；只有热力图、桑基图等高级场景才使用 ECharts。普通表格继续使用工作台原有组件；需要冻结列、行内编辑或虚拟滚动时再选择 Tabulator。

## 6. 安全和离线边界

- Mermaid 固定使用 strict 安全等级，不加载远程图标或脚本。
- Quill 输出进入不可信 HTML 区域前必须经过 security.sanitize@1。
- Leaflet 可以显示本地 GeoJSON、矢量和点位；房间未获得联网权限时不得引用公共瓦片 URL。
- Tabulator 不使用 ajax 直连；外部数据只能经过房间数据库、文件接口或受控网络接口。
- mathjs 不对不可信输入直接调用 evaluate。
- 所有资源具有 SHA-256、许可证副本与 SBOM 记录；ECharts 和 mathjs 的 NOTICE 也随模块分发。
- Quill 固定为 2.0.2。2.0.3 在本轮 npm 审计中命中一项低危 XSS 公告，因此未采用。

## 7. 验收结果

Electron 离线冒烟不只检查全局变量存在，还分别创建或执行了数据网格、排序、Mermaid SVG、ECharts、Quill 编辑器、Leaflet 本地矢量地图、mathjs 运算、统计均值、Cropper、Konva 图形、D3 SVG 和 Cytoscape 无头关系图。全部 39 个模块在同一受限房间中加载成功，CSS 资源也经过实际加载检查，普通互联网出站尝试为 0。

维护时执行：

    npm run build:room-modules
    npm run build:compliance
    npm test
    npm run smoke -- --offline-audit

新增或升级模块时必须同步更新固定版本、许可证证据、资源哈希、AI 选型规则、Agent 使用说明与 Electron 行为测试。
