千万间 Roomillion 0.3 Alpha 试点验收包
================================

请在一台 Windows 10/11 x64 普通用户电脑上解压整个 ZIP，不要只复制 EXE。

第一步：断开外网，确认没有使用“以管理员身份运行”。
第二步：双击“验证便携版.cmd”。脚本会核对 SHA-256，并在 PATH 仅保留 Windows System32 的条件下运行自动冒烟；同时拦截 HTTP、HTTPS 和 WebSocket 请求，出站次数不是 0 就判定失败。
第三步：保留生成的 pilot-result.json；其中不记录用户名、文件路径或业务数据。
第四步：打开“试点验收手册.md”，继续完成人工场景并回填结果表。
第五步：双击“试点反馈表.html”，填写匿名编号和任务结果，导出 JSON 给试点负责人。

试点负责人双击“汇总试点结果.html”，一次选择 5～20 份反馈 JSON，即可自动计算阶段指标并导出汇总。反馈和汇总页面都只在本地浏览器运行，不会自动上传。

自动验收不能代替以下人工检查：
- 是否出现 UAC、SmartScreen 或组织杀毒软件告警；
- 测试期间是否确实断网；
- 非开发用户能否看懂导入权限、完成备份恢复和程序回退。

如果 SHA-256 不匹配，脚本不会启动便携版，请停止测试并重新取得验收包。
