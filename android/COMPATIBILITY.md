# 安卓房间兼容性记录（实验工程）

截至 2026-10-05，以下结论来自源码清单审查以及 Android 12/API 31 手机、Android 16/API 36 手机与平板模拟器测试。三种环境各 61 项设备测试中，59 项常规测试通过、2 项需要临时凭据的真实服务测试按预期跳过，Android Lint 通过。常规测试覆盖导入导出、房间卸载及数据和授权清除、房间直接调用分块文件导出、图片/音频桥接与权限、私有 Blob 读写及迁移、隔离、数据库、授权、本地模型网关模拟响应、房间内切换默认模型的通知、模型连接测试入口、服务端错误脱敏、系统返回，以及物资台账和会议行动项的新增、删除操作。两项可选测试在此前版本分别于三种环境单独通过，并在本次最新源码的 API 36 手机模拟器重新通过：AI 辩论场完成正方、反方和裁判的真实调用，数据库记录确认正反方分别使用两套配置；物资台账和会议行动项的 AI 按钮完成真实调用并显示结果；每次测试后删除临时凭据。文档房间的 PDF/Word 模块与通过系统选择器打开、预览、转换和保存的按钮流程也在三种环境通过。Android 16 手机模拟器开启飞行模式后，物资台账和文档房间的离线操作复测通过。另在手机模拟器上走通系统文件选择器导入和触控保存，在平板模拟器上检查工作台宽屏布局；这不代替不同厂商真机 WebView、真实平板和其他真实模型服务的验收。一次性测试签名下的 Release APK 已构建，由 `apksigner` 验证 v2 签名，并在 API 31 专用模拟器安装、启动和显示工作台；包内核对有 14 个离线模块及对应许可。测试密钥已清除，测试 APK 留在 Git 忽略的本地验收目录，不能作为正式版分发。导入预检只报告已知缺口；“可安装”不代表全部按钮已验证。

最新源码另在 API 36 平板模拟器完成一次测试签名 Release APK 的安装与启动，确认首页“隐私与数据”入口显示；测试签名和 APK 已清除。正式签名版本仍需实体设备验收。

API 36 手机模拟器还以一次性测试签名验证了 Android 应用本身的升级：0.1.0（`versionCode=1`）导入公开物资台账并写入记录，安装同签名的 0.1.1（`versionCode=2`）后房间和 SQLite 记录可见，旧版回装被系统以版本降级拒绝。`apksigner` 核验两包签名；测试密钥已删除。本地证据留在 Git 忽略的 `release/android-upgrade-smoke/`，这不替代正式签名或真机验收。

构建入口检查发现旧配置只识别任务名含 `Release` 的命令，`assemble` 曾可在无签名时把 `assembleRelease` 纳入任务图。现改为检查实际任务图：无签名时 `assemble`、`build`、`bundleRelease` 都拒绝，`assembleDebug` 允许；提供本机测试签名时 `assemble --dry-run` 通过。此检查不代表已完成正式签名发布。

发布后校验脚本已对两个一次性测试签名 APK 验证签名方案、单一签名者、证书指纹、包名和版本号；错误指纹或版本号被拒绝。正式签名尚未提供，因此脚本没有对正式包的验收结果。

安全边界测试曾复现房间可设置第一方 Cookie，并在重开时保留。现已禁用房间 WebView Cookie，启动时清理旧 Cookie 和网页存储。最新源码在三种模拟环境各完成 61 项设备测试：59 项通过、2 项真实模型用例按预期跳过，Android Lint 通过。测试覆盖旧 Cookie 清除、重开后不能写入持久 Cookie，以及 Service Worker 注册探针未成功；不同厂商 WebView 仍需实体设备复核。API 36 手机模拟器还重新通过了双模型辩论及两个业务房间的真实文本 AI 烟测，临时凭据已核实清理。

关闭房间时取消进行中的 AI 请求后，API 36 手机模拟器完成最新源码的 61 项设备测试：59 项通过、2 项需要真实凭据的测试按预期跳过；Android Lint 通过。新增测试确认请求在发出前取消不会建立连接，进行中取消会断开连接且请求不返回旧回答；断开连接自身抛错也不会妨碍房间关闭。API 31 手机和 API 36 平板也已完成本次修改的 61 项完整设备测试。

最新源码在三种模拟环境均完成了完整设备测试：各 61 项，其中 59 项通过、2 项真实服务测试按预期跳过，Android Lint 通过。新增测试覆盖普通和流式聊天接口的分段文本及空流片段，以及音频分析室通过系统选择器选取音频、在读取前拒绝超出安卓媒体上限的文件；文件来源不提供可靠大小时，也会在分块复制期间强制上限并清除暂存。最新源码在 API 36 手机模拟器还重新通过了两项真实模型烟测。

首批已打包并在模拟器实际加载的 14 个官方模块是 `data.date@1`、`data.decimal@1`、`data.csv@1`、`data.search@1`、`ui.chart@1`、`security.sanitize@1`、`document.markdown@1`、`archive.zip@1`、`utility.qrcode@1`、`document.spreadsheet@1`、`document.pdf.view@1`、`document.word.write@1`、`document.word.read@1`、`document.word.preview@1`。二维码模块已在房间 WebView 中生成 PNG Data URL；基础 XLSX 模块已在 WebView 内完成中文和数字表格写入、读取往返。仅声明了模块的房间才能取得资源；未声明或未移植模块会被拒绝。Markdown 模块仍须同时声明 HTML 清理模块。安卓 `room.documents.markdownToPdf` 使用系统 PDF 绘制，复杂样式与桌面排版不完全相同。

其余 25 个桌面官方模块暂未移植或逐项验收：

- 文档与字体：`font.cjk@1`、`document.pdf.fontkit@1`、`document.pdf.compose@1`、`document.pdf.report@1`、`document.pdf.table@1`、`document.spreadsheet.rich@1`、`document.presentation.write@1`。
- 界面、媒体与可视化：`media.html-image@1`、`ui.datagrid@1`、`ui.sortable@1`、`diagram.mermaid@1`、`ui.chart.advanced@1`、`editor.richtext@1`、`map.leaflet@1`、`math.general@1`、`stats.simple@1`、`media.cropper@1`、`graphics.canvas@1`、`visualization.d3@1`、`visualization.graph@1`。
- 3D 与游戏：`graphics.three@1`、`physics.rapier@1`、`game.input@1`、`game.audio@1`、`game.assets@1`。

同一 `.room` 包可以跨平台交换，但只有安卓宿主已实现的 Room SDK、模块和权限组合才能正常运行。桌面最多可接受的包尺寸远大于当前安卓实验预算；超限时会在导入前明确报错。
