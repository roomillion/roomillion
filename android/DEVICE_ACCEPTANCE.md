# 安卓实体设备验收

此表用于首个侧载内测版，至少覆盖两家不同厂商的手机和一台实体平板。模拟器结果不能填写为真机结果。每台设备使用专门的测试环境；自动测试会安装调试版宿主并写入测试房间和数据，不应在存有正式用户数据的设备上运行。

## 自动测试

安装 JDK 17、Android SDK 并开启设备的 USB 调试后，在仓库根目录运行：

```powershell
$env:JAVA_HOME = '本机 JDK 17 路径'
$env:ANDROID_HOME = '本机 Android SDK 路径'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\android-device-acceptance.ps1 -Serial 'adb devices 显示的设备序列号'
```

脚本要求设备上尚未安装千万间安卓宿主或旧测试包；它不会覆盖已有安装。它会构建资源与调试 APK、运行 Android Lint、在指定设备执行完整设备测试，并将设备型号、Android/WebView 版本、APK SHA-256 和原始测试输出写入本机 `release/android-device-acceptance/`。该目录包含设备序列号，只供本地验收，不应提交仓库。两项需要真实模型凭据的测试会跳过，须按下表另测。`-AllowEmulator` 仅用于脚本自测，不能替代实体设备结果。

一次性测试签名的 v1→v2 升级已在模拟器保留公开房间和一条数据库记录，并确认降级被拒绝；正式包这一行仍须在实体设备上用实际长期签名重新完成。

遇到失败时记录设备信息、操作步骤、应用版本、可复现性和本地诊断报告。分享诊断前先检查内容，勿附模型密钥、个人文件或完整房间数据。
